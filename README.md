# Windows 11 Setup Guide

A step-by-step guide for setting up an AI gateway on Windows 11.

Built and documented by **Todd Nicholas** with the help of HAL.

---

## Requirements

- Windows 11
- Node.js 22+
- Anthropic API key
- Discord bot token

---

## Workspace Structure

The agent's configuration is stored at `~/.agents/main/`:

| File | Purpose |
|------|---------|
| `SOUL.md` | Agent personality and core values |
| `MEMORY.md` | Long-term memory across sessions |
| `HEARTBEAT.md` | Health and activity monitoring |
| `IDENTITY.md` | Agent identity definition |
| `TOOLS.md` | Available tools and capabilities |
| `USER.md` | User preferences and profile |
