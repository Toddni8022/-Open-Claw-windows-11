## Config File Location

All OpenClaw configuration lives in your home directory:

```text
~\.openclaw\
├── config.json          ← global settings
└── agents\
    └── main\            ← default agent workspace
        ├── SOUL.md
        ├── IDENTITY.md
        ├── MEMORY.md
        ├── TOOLS.md
        ├── USER.md
        └── HEARTBEAT.md
```

---

## Global Configuration (`config.json`)

Open the file in any text editor:

```powershell
notepad ~\.openclaw\config.json
```

### Available Keys

| Key | Type | Default | Description |
|---|---|---|---|
| `anthropicApiKey` | string | — | Your Anthropic API key (required) |
| `discordToken` | string | — | Your Discord bot token (required) |
| `gatewayPort` | number | `3000` | Port the local gateway listens on |
| `model` | string | `claude-3-5-sonnet-20241022` | Anthropic model to use |
| `maxTokens` | number | `4096` | Max tokens per response |
| `logLevel` | string | `info` | Logging verbosity (`debug`, `info`, `warn`, `error`) |
| `memoryLimit` | number | `50000` | Max characters stored in `MEMORY.md` before a trim warning |

### Example `config.json`

```json
{
  "anthropicApiKey": "sk-ant-...",
  "discordToken": "MTI...",
  "gatewayPort": 3000,
  "model": "claude-3-5-sonnet-20241022",
  "maxTokens": 4096,
  "logLevel": "info",
  "memoryLimit": 50000
}
```

> **Security:** Never commit `config.json` to version control — it contains your API keys.

## Agent Workspace Files

### SOUL.md

Defines the agent's core personality, values, and behavioural guidelines.

```markdown
# Agent Soul

You are HAL — a curious, helpful, and honest AI assistant.
Your primary goal is to assist Todd with development tasks and research.

## Core Values
- Accuracy over speed
- Transparency about uncertainty
- Respect for user privacy
```

---

### IDENTITY.md

Short factual description of the agent — name, purpose, and capabilities.

```markdown
# Agent Identity

**Name:** HAL
**Purpose:** Personal AI assistant and development companion
**Platform:** Discord (Guild: Todd's Server)
**Capabilities:** Web search, code execution, file access, memory
```

---

### MEMORY.md

Long-term persistent memory. The agent reads this file at the start of every conversation and appends new facts
as they are encountered.

Format:

```markdown
# Memory

## 2025-06-01
- Todd prefers TypeScript over JavaScript for new projects
- Deployment target is always Windows 11 + IIS

## 2025-06-15
- Todd's Discord handle is Toddni8022
```

---

### TOOLS.md

Declares which tools the agent is allowed to use.

```markdown
# Available Tools

- web_search: Search the internet for up-to-date information
- read_file: Read files from the local workspace
- write_file: Write or modify files in the workspace
- run_powershell: Execute PowerShell commands (requires confirmation)
- send_discord_message: Send a message to a Discord channel
```

---

### USER.md

Stores preferences about the user to personalise responses.

```markdown
# User Profile

**Name:** Todd
**Timezone:** UTC-5 (Eastern)
**Communication style:** Concise and direct
**Preferred language:** English
**Interests:** AI, gaming, Windows development
```

---

### HEARTBEAT.md

Auto-updated by the gateway with health and activity metrics. Do not edit this file manually.

## Environment Variables

You can override `config.json` values using environment variables:

| Variable | Config Key Override |
|---|---|
| `OPENCLAW_API_KEY` | `anthropicApiKey` |
| `OPENCLAW_DISCORD_TOKEN` | `discordToken` |
| `OPENCLAW_PORT` | `gatewayPort` |
| `OPENCLAW_MODEL` | `model` |
| `OPENCLAW_LOG_LEVEL` | `logLevel` |

Set them in PowerShell:

```powershell
$env:OPENCLAW_API_KEY = "sk-ant-..."
openclaw gateway start
```

## Multiple Agents

To run more than one agent, create additional directories under `~\.openclaw\agents\`:

```powershell
New-Item -ItemType Directory ~\.openclaw\agents\research
openclaw workspace init --agent research
openclaw gateway start --agent research --port 3001
```

Each agent maintains its own isolated workspace files and can be started on a different port.
